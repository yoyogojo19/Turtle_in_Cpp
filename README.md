# Turtle in C++
## Basics
This is a basic recreation of Turtle (from pyhton) in C++.
To get the code simply download the turtle folder and open it.

### Linux
To use this code make sure you have a **C/C++ compiler**, verafy for **clang** or **g++** bye typing ,in a **terminal**, `g++ --version` or `clang --version`. If you don't have any of theme type `sudo apt-get install g++` for g++ and `sudo apt install clang` for clang.

Then you can right `./run.sh`

### Windows
To run the code on **Windows** download this [C/C++ compiler](https://sourceforge.net/projects/mingw/files/OldFiles/) and double-click the **run windows.bat** file

## For more advanced pepole
If you feel advanced enough, feel free to change the code in **turtle command.cpp**
