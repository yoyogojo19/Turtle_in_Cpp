# Turtle in C++
## Intro
This is a basic recreation of Turtle (from pyhton) in C++.

## Get the code running
To get the code simply go to [releases](https://github.com/yoyogojo19/Turtle_in_Cpp/releases) for this repositorie and **download the "source code (zip)"** file. Then you go in your files find Turtle_in_Cpp and unzip it (this action is called extraction). Once it hase extracted you can open it to the main file (Turtle_in_Cpp).

### Linux
To use this code make sure you have a **C/C++ compiler**, verify for **g++** by typing ,in a **terminal**, `g++ --version`. If you don't have any of theme type `sudo apt install build-essentials`. This code only allows g++.

Then you can execute `./run.sh` from the root directory.

### Windows
To run the code on **Windows** download this [C/C++ compiler](https://sourceforge.net/projects/mingw/files/OldFiles/) and double-click the **run windows.bat** file

## For more advanced pepole
If you feel advanced enough, feel free to change the code in **turtle command.cpp**
